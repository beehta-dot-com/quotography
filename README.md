# Quotography

Quotography is a lightweight, fully client-side web tool designed to help you create stunning, high-quality quote graphics. Built entirely with HTML5 Canvas, CSS, and Vanilla JavaScript, it runs directly in your browser without the need for servers, databases, or complex software installations.

Whether you are creating content for social media, blogs, or personal projects, Quotography gives you granular control over typography, image placement, and alignment.

## ✨ Features

* **Zero Installation:** Runs locally from a single `.html` file. No dependencies required.
* **Advanced Background Control:** Upload any image and easily pan, zoom, and crop it to fit your custom canvas dimensions.
* **Rich Typography:** Choose from curated Google Fonts across various styles (Typewriter, Elegant Serif, Modern Sans-Serif, and Handwritten Script).
* **Precision Alignment:** Features a high-contrast, toggleable alignment grid (click the preview to toggle) and adjustable side margins for perfect text framing.
* **Custom Signatures & Logos:** Add dedicated author signatures and upload custom watermark logos with independent scaling and X/Y axis positioning.
* **Smart Resets:** Quickly revert to default settings using global or section-specific reset buttons without losing your uploaded images or typed content.
* **Instant Export:** One-click download exports your creation directly as a crisp `.png` file.

## 🚀 How to Use

1. Clone or download this repository.
2. Open `quote_generator.html` (or `index.html` if renamed) in any modern web browser (Chrome, Firefox, Safari, Edge).
3. **Canvas & Background:** Set your desired image dimensions (e.g., 1080x1080) and upload a background image. Use the sliders to zoom and pan.
4. **Customize Text:** Type your quote and signature. Adjust fonts, sizes, colors, and line spacing.
5. **Add a Logo:** Upload a transparent PNG logo and use the sliders to place it exactly where you want it.
6. **Download:** Click "Download Image" to save your final graphic.

*(Note: While the tool functions offline, an active internet connection is required the first time you load it to fetch the custom web fonts from Google Fonts).*

## 🛠️ Tech Stack

* **HTML5** (Structure & Canvas API)
* **CSS3** (Styling & Responsive UI)
* **Vanilla JavaScript** (Logic & Image Rendering)
